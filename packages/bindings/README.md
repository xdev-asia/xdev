# @xdev/bindings

TypeScript types generated from the Rust crates for every value that crosses the desktop app's Tauri IPC boundary: what each command takes and returns, and the payload of each event. The desktop UI imports them from `@xdev/bindings`, so a Rust change that breaks the UI fails its typecheck.

`src/` is generated by [ts-rs](https://github.com/Aleph-Alpha/ts-rs); do not edit it. After changing a Rust type that crosses the boundary, regenerate from the repo root and commit the result:

```sh
cargo test -p xdev-desktop export_bindings
```

The desktop crate's build embeds the built frontend, so run `corepack pnpm --filter desktop build` once first. CI regenerates the files and fails if they differ from what is committed.

The roots are listed in `apps/desktop/src-tauri/src/bindings.rs`; each brings the types it contains. A new command's argument or return type goes there, and its crate's type needs `#[cfg_attr(feature = "ts", derive(ts_rs::TS))]`.
