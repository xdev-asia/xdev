# Colour schemes in `terminalThemes.json`

Each scheme is the published palette of the project named below, used under that project's licence
(the licence text is kept by the upstream project; every entry here is MIT). Values were copied from
a public aggregate of these palettes and mapped to the xterm names (ANSI "purple" is "magenta");
`cursorAccent` is the scheme background. The same source and licence sit in each JSON entry.

| id | upstream | licence |
| --- | --- | --- |
| dracula | https://github.com/dracula/dracula-theme | MIT |
| one-dark, one-light | https://github.com/atom/atom (One Dark / One Light syntax themes) | MIT |
| nord | https://github.com/nordtheme/nord | MIT |
| tokyo-night | https://github.com/tokyo-night/tokyo-night-vscode-theme | MIT |
| gruvbox-dark | https://github.com/morhetz/gruvbox (MIT/X11 per its README and package.json) | MIT |
| catppuccin-mocha, catppuccin-latte | https://github.com/catppuccin/catppuccin | MIT |
| solarized-dark, solarized-light | https://github.com/altercation/solarized | MIT |
| github-light | https://github.com/primer/github-vscode-theme | MIT |

Left out: Monokai. No permissive licence for its palette could be verified.
